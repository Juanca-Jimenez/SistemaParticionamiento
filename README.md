# GraphPartitionOptimizer

Sistema de particionamiento óptimo para sistemas distribuidos, orientado a la minimización de comunicación entre componentes mediante algoritmos exactos y heurísticos aplicados sobre grafos y matrices de dependencias.

## Tecnologías
- Python
- NumPy
- Matplotlib

## Objetivo
Minimizar el costo de comunicación entre grupos de componentes utilizando técnicas de optimización y teoría de grafos.
